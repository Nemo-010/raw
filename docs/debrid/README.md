# debrid

Retrieval, not storage. A debrid service holds a subscription to many file hosts
and turns one account into downloads from all of them. The adjacent paths do the
same job without a multi-hoster: usenet, torrent-to-cloud, a hosted downloader, an
index, a relay or a bot.

The question is not which service is best. It is:

1. **Which service turns the least money, or nothing, into the most bytes
 retrieved per month?**
2. **What breaks first: a daily fair-use cap, a host-coverage exclusion, a
 server-side queue, or the identity gate?**

## The answer

⭐ **USD 3.00 a month is enough.** TorBox Essential at USD 3.00, a public index and
a browser front end retrieve anything a multi-hoster can retrieve, with no
hardware. Its 200 GB per-object cap is the only wall that matters at this scale.

⭐ **For nothing, a reader can obtain 1,116 GB (1,039 GiB) in month one and 1,046 GB
in month two** from fourteen signups and five anonymous endpoints, with no card.
Month one clears 1 TiB by 16.5 GB. Month two falls 5% short.

⛔ **Price is not the first gate. The caller's address is.** Five of the nine
best-known services refuse datacenter, VPS, proxy or cloud addresses in their own
terms, and every machine a reader can rent is one of those. TorBox is the only
one whose documentation accepts any address; three publish no rule at all.

⚠ **Nothing in this topic was measured end to end.** Every ceiling is a published
counter, except the throughput figures in [`free/relays.md`](free/relays.md) and
[`free/open-libraries.md`](free/open-libraries.md), which are measured.

## The vocabulary

| term | means |
| --- | --- |
| host coverage | the number of file hosts a service will fetch from on the reader's behalf |
| unrestrict | the call that converts a host URL into a direct link the reader can read |
| cache | a service that already holds the object, so the read is immediate |
| fair use | an undisclosed daily cap a service enforces instead of publishing a quota |
| seedbox | a rented machine that runs a BitTorrent client and serves the result |
| usenet | a separate retrieval network with its own providers and indexers |
| daixia | a Chinese per-file fetch service: a third party retrieves a pan link for a fee |

## The standing caveat

The debrid market moves monthly: prices, host counts, free tiers and payment rails
all change without notice. This topic is verified on a 30-day window
(`scripts/dossier/staleness.policy.json`), among the shortest in the corpus (only
`netdisk-pan` is shorter), because a figure older than a month is a hypothesis here.
