# full run touches each host four times (two arms x two rounds).
#
# These are NOT a scan. Every host here is a site that publishes itself, a
# package mirror, or a public AList instance that already answered in the
# corpus's own sweep. No range is scanned and no host is probed that did not
# ask to be.
#
# The five AList entries are the point of the list: they are the population
# docs/netdisk-pan/ is about, and they cost 2-4 s each, which is why the live
# ratio is dominated by the network rather than by either prober.
