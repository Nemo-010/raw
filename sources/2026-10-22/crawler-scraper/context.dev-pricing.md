Can I crawl an entire website?

Yes. Crawl discovers and scrapes up to 500 pages into Markdown in one call, with controls for depth, page count, URL patterns, and subdomains. For larger sites, run Batches in crawl mode and collect results through pagination or a completion webhook. Use Map when you only need the URLs.

What are the rate limits, and how can I increase them?

Core API limits cap concurrent requests per organization: Free allows 2; Developer 10, Pro 100, Growth 250, and Scale 500. Plans have no per-minute cap by default. Existing accounts keep their current allowances until they change plans; custom overrides can apply to either limit or both. The dashboard shows your effective limits. Batches, Monitors, webhook deliveries, logs, and feedback have separate organization limits. Enterprise can have custom limits; Logo Link has a separate quota.

Why am I getting timeout errors?

Scrape waits up to 90 seconds by default. For slow or heavily protected pages, raise timeoutOpts.milliseconds (up to 300,000), set timeoutOpts.behavior to return-partial to keep the outputs that finished, and give your HTTP client a longer timeout than the request. Use Batches for large URL lists, and Prefetch to warm uncached domains before a Brand request.

What SDKs are available?

We provide official SDKs for TypeScript, Python, Ruby, Go, and PHP.

How can my agent sign up?

AI agents can register and obtain API credentials programmatically using our agent authentication guide (auth.md). You will still need to sign in or verify your email. Share the link with your agent:

How fresh is the brand data? How often is it updated?

Brand Retrieve may reuse cached data up to its documented maxAgeMs, which defaults to about 90 days and is clamped to 0 through one year. A value of 0 requests a fresh Brand retrieval. For a specific correction or rebrand, use [https://www.context.dev/update](https://www.context.dev/update) and treat returned media URLs as external resources that your application should handle defensively.

Do you support subdomains?

Yes, subdomains are fully supported.

We are constantly adding new data points to the API and have more data under the hood that we don't surface yet. If you need a specific data point, please contact us at [hello@context.dev](mailto:hello@context.dev) and we will be happy to surface it.

How do API credits work?

Scrape starts at 1 credit, or 2 with browser actions. Structured JSON extraction against your schema adds 4 when it succeeds, so 5 credits per page. Highlights and Product add 1, and PDF OCR adds 1 per recovered page. Brand and Styleguide cost 10 credits. Answers costs 10 in Fast mode or 100 in Ultra. Web and news search cost 1 credit per 10 results; People costs 20 per match. Logo Link has a separate quota.

Are there extra fees for JS rendering, anti-bot bypass, or premium proxies?

JS rendering, anti-bot bypass, and proxies are included in the base scrape price. Browser actions raise the base to 2 credits. Successful JSON extraction adds 4 credits. Highlights and Product add 1, and PDF OCR adds 1 per recovered page.

Am I billed for failed requests?

Most failed requests are not billed. Not-found responses (404) are billed at the request’s base price. Scrape can return a 200 with failed outputs: it charges when at least one output succeeds or the target page is missing. Check key\_metadata.credits\_consumed for the amount charged.

What happens when my API credits run out?

The Free plan includes 1,000 API credits that renew every month. Paid plans can use Auto-Topup in 1K-credit blocks: Developer $2.20, Pro $1.80, Growth $1.40, and Scale $1.00 for new subscriptions. Existing subscriptions keep their rates. With insufficient credits and no available top-up, any plan returns 401 USAGE\_EXCEEDED. Logo Link has a separate quota.

What's the difference between API credits and Logo Link?

They are separate products with separate quotas. API credits meter the documented API endpoints. Logo Link returns a square logo through a direct image URL and does not consume API credits. Core API requests use the plan concurrency limit; Logo Link image delivery follows its separately documented quota and delivery policy.
